# ClassPilot

面向生理与生化课程的轻量学习助手，支持课堂标记、每周复习、考前大纲和每日任务调整。

打开 GitHub Pages 链接即可使用。学习标记、随记和回答保存在当前浏览器的本地存储中，不上传到 GitHub，也不会在设备间自动同步。可在页面设置中导出、恢复完整备份。

课程内容和章节进度可在页面中修改；预置课程材料是演示和暂估内容，具体学习内容需以教材及课件为准。

## 用自己的教材生成本节

在「课堂」或「设置与课程内容」中点「上传 PDF 并生成本节」，选择生理或生化、目标章节、单章教材或课件 PDF，并填入自己的 OpenAI API 密钥。网页会请求 Responses API，预览本节目标、机制、知识点与自测答案；确认后才替换课程内容。生成内容会进入每日和每周复习。支持新增下一章。

PDF 会发送到 OpenAI API，可能产生 API 费用。网页不保存 API 密钥或 PDF 原文件；只把确认后的课程内容保存在当前浏览器，并可通过完整备份导出。AI 生成的医学内容需对照原文与老师要求核对。建议上传单章 PDF，文件上限 20 MB。此功能使用浏览器直接连接 API，不适合共享密钥或多人共同使用。
